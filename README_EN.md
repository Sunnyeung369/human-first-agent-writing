# Human-First Agent Writing

A practical, auditable workflow for research, drafting, editing, and fact-checking with AI agents.

The project favors concrete language, visible uncertainty, source-aware claims, and a final human-voice edit. It does not promise automatic quality, hidden browsing, or real parallel execution when the host does not provide those capabilities.

## Try it in 30 seconds

Open [the demo](examples/30-second-demo.md), copy the prompt, and give it to an agent host that supports custom skills.

## Roles

Chief coordinates; Researcher gathers context; Writer drafts; Editor removes template language; Fact-Checker verifies claims; Archivist connects prior material.

The old `ai-agent-team` invocation remains accepted for compatibility. See the [Chinese README](README.md) for the full guide.
